# Axis - Installation Guide (Phase 2)

Welcome to Axis! Follow these instructions to install and run the Axis Desktop App.

## Installation Steps
1. Double click on `Axis Setup 1.0.0.exe` (found in the `dist` folder).
2. The installer will guide you through the process and create a Start Menu shortcut.
3. Open the "Axis" app from your desktop or start menu.

## Important Notes

- **Windows SmartScreen Warning**: Since this executable is not code-signed (expected for Phase 2), Windows SmartScreen might show a warning ("Windows protected your PC"). Click **More info** -> **Run anyway** to proceed.
- **First Render Delay**: The very first time you render a video or run a preview, Axis may take a moment to download Chromium and FFmpeg in the background (which are required for headless rendering). Please be patient during the first run.

## Requirements
- Windows 10 or 11
- Internet connection (only required on the very first run to download the rendering engine binaries).

Enjoy creating motion-graphics seamlessly on your desktop!
